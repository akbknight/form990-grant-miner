Community / Endowment / Fund layer — verified metadata dataset. Verified This layer now ships the verified 90-entity research file (community foundations, federation endowments, DAF programs, supporting orgs, donor-advised funds). Each record carries an IRS/registry verification status, filing history, EIN, related federation, source links, and a confidence score. Grant- and expense-line extraction from the underlying 990 filings has not been performed in this build: financial totals, classification, and per-grant Jewish/Non-Jewish/Misc breakdowns are pending — not extracted. Review-queue items capture every unclear / needs review, included in parent group return, internal fund with no separate 990, missing-filing, low-confidence, and possible double-counting condition.
Multi-layer money flow — possible double-counting. Audit A grant from a private Foundation to a Federation that then re-grants through its affiliated Community Foundation, Endowment, or Donor-Advised Fund can appear at multiple layers. Until 990 line items are extracted for the verified Community/Endowment/Fund entities, the dashboard cannot net these flows out. Layer totals across Foundation + Federation + Community / Endowment / Fund should therefore be treated as upper bounds rather than additive. The Review Queue surfaces a possible_double_counting_with_federation_parent category covering every CEF entity that is tied to a Federation parent in the verification CSV.
